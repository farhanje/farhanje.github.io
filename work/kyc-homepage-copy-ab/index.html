Production A/B Test: KYC Homepage Copy

A designer-led experiment on AstraPay’s production homepage to improve KYC conversion by changing copy only.

Context

Homepage KYC copy had become stale. We ran a short production test to find messaging that improves KYC start and submit.

Variants

A — Feature Highlight

“Mau Transfer & Tarik Tunai? → Upgrade & nikmati akses ke semua fitur!”

B — General Highlight

“Akses Fitur Masih Terbatas? → Upgrade yuk, biar bisa transfer & tarik tunai!”

C — Monetary Highlight

“Mau Voucher Senilai 100rb? → Cukup upgrade akun, super cepat!”

As-is (Legacy)

“Dapatkan Bonus 2x Lipat → Cukup upgrade akunmu, super mudah.”

Method

  • Random assignment for A/B/C variants
  • Funnel analysis with unique users per step
  • Stat testing to support ship decision

Results

Summary: All new variants beat legacy copy. Variant C was strongest to trigger Start KYC; submit rates among A/B/C were close.

Decision

  • Ship C if goal is maximum volume.
  • Ship B if goal is efficiency without voucher promise.
  • Retire as-is.

Learnings

  • Entry copy can move the funnel meaningfully without UI changes.
  • Separate “volume” vs “efficiency” decisions to avoid stakeholder confusion.
