Why a blog

I use a blog as a low-friction way to document decision frameworks, learnings, and small UX insights. It also helps me write more clearly—without turning everything into a slide deck.

How this site handles blog posts

  • Each post is a simple HTML page under /blog/posts/<slug>/.
  • No backend, no database—works perfectly on GitHub Pages.
  • Later, we can add an index generator or migrate to Jekyll if you want true CMS-like posting.
